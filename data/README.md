# Training data

All training data is built by `src/takehome/build_data.py` from three public datasets, one per
expert, plus a union (concatenation) used by the control run. Nothing is hand-written and no
benchmark item, answer, reference patch, hidden test or test feedback is used for training or for
checkpoint selection. Manifests with every filter count and the sha256 of each output file are in
`data/manifests/<expert>.json`; the per-example IDs are in `data/processed/<expert>/{train,dev}.ids`
(the JSONL files themselves are regenerated by the script and not committed).

```bash
python -m takehome.build_contam                       # benchmark texts, decontamination only
python -m takehome.build_data --expert swe  --n-train 2000
python -m takehome.build_data --expert term --n-train 2000
python -m takehome.build_data --expert sci  --n-train 4000
python -m takehome.build_data --expert union          # swe + term + sci
```

## Sources and licenses

| Expert | Source (Hugging Face) | License | Format | Raw rows |
|---|---|---|---|---|
| `swe` | `Kwai-Klear/SWE-smith-mini_swe_agent_plus-trajectories-66k` | MIT | mini-swe-agent text trajectories (THOUGHT + one bash block per turn) on SWE-smith synthetic bugs in 123 Python repos | 65,994 |
| `term` | `open-thoughts/OpenThoughts-Agent-v1-SFT` | Apache-2.0 | Terminus-2 JSON keystroke trajectories (Harbor) on synthetic terminal tasks | 15,209 |
| `sci` | `nvidia/OpenScienceReasoning-2` | CC-BY-4.0 | single-turn science questions with `<think>` reasoning traces | 1,600,812 |

`MegaScience/MegaScience` was considered and rejected (CC-BY-NC-SA-4.0).

Why these: each expert is trained in the exact protocol it is evaluated with. SWE-bench Pro and
ASI-Bench are run with mini-swe-agent's text-based bash format, Terminal-Bench with Terminus-2,
HLE as single-turn reasoning. This keeps the expert/benchmark mapping clean and makes the merge
question meaningful: can one model keep two different agent protocols plus scientific reasoning?

## Cleaning and filtering (in order)

| Step | Rule |
|---|---|
| Normalize | to `{"messages": [{role, content}]}`; the chat template of the pinned base renders them |
| Length | drop conversations over 60,000 characters (~16K tokens); `sft.py` drops any example over 16,384 tokens after tokenization |
| Exact dedup | sha1 of the normalized task-specific prompt span (`task_text`: the `<pr_description>` block for swe, the `Task Description` block for term, the question for sci), one example per task |
| SWE-Pro repo exclusion | drop any SWE-smith repo that is one of the 11 SWE-bench Pro repositories (none matched) |
| 13-gram decontamination | drop an example if any 13-word n-gram of its prompt appears in a benchmark text: all 642 SWE-bench Pro v2 problem statements + requirements, all ASI-Bench seed31415 prompts b1-b4 (240), all 89 Terminal-Bench 2.0 instructions, and the HLE questions once access is granted |
| Near-dup | MinHash (64 perms, 5-word shingles, Jaccard >= 0.8) on the task-specific span, inside a shuffled working pool |
| Difficulty tier | agent data by number of assistant turns (easy <= 10, medium 11-25, hard > 25); sci by trace length (easy <= 8K chars, medium <= 24K, hard > 24K) |
| Sampling | stratified: up to one third of the training budget per tier, remainder filled from the pool |
| Dev split | 4% of task groups held out (by SWE-smith repo, by Terminus task, by question), capped at 200 examples; dev groups never appear in train |

| swe | 29,466 | 8,151 | 8,150 | 0 | 2,000 | 200 | 81 / 1,253 / 666 |
| term | 14,471 | 14,464 | 14,461 | 5,847 | 2,000 | 200 | 1,317 / 666 / 17 |
| sci | 1,538,163 | 1,537,418 | 1,537,414 | 24 | 4,000 | 200 | 1,333 / 1,334 / 1,333 |
| union | | | | | 8,000 | 600 | 2,731 / 3,253 / 2,016 |

Scale and mix differ on purpose: one SWE or Terminal trajectory is 6-18K tokens and 14-67 turns,
one science example is ~3K tokens, so the science expert gets 2x the examples for a comparable
token budget (2,000 x ~11K vs 4,000 x ~3K tokens per epoch). The terminal pool is easy-heavy
because the source is; hard terminal trajectories (> 25 turns) are rare in OpenThoughts-Agent.

## Contamination checks

- Benchmark texts are collected in `data/bench/contam_texts.jsonl` (git-ignored) only to filter;
  they are never trained on. Counts: SWE-Pro 642, ASI-Bench 240, TB2 89 (HLE pending access).
- Removed by the 13-gram rule: swe 1, term 3, sci 4.
- No dev set is drawn from any benchmark; checkpoint and merge selection use only these dev sets.
